# Nexus v0.1.0

**Released:** 2026-10-18 · **Tag:** `v0.1.0`

## What is Nexus

Nexus is a local-first, open-source companion for connecting your Android phone
and desktop. It discovers your devices on the local network, pairs them once by
comparing a short code on both screens, and then keeps a direct TLS 1.3
connection between them so the clipboard stays in sync. No account, no server,
no cloud.

## What's included

- **Discovery** — automatic mDNS (`_nexus._tcp`) discovery on the local network.
- **Pairing** — 6-digit short-authentication-string confirmation, with each
  device's certificate pinned afterwards.
- **Trusted devices** — trusted devices reconnect automatically; unpaired
  devices are rejected.
- **Encrypted connection** — mutual TLS 1.3 directly between the devices, with
  application-layer certificate pinning.
- **Clipboard sync** — two-way plain-text sync with loop prevention.
- **Desktop app** — a Tauri app for Windows with a light, minimal interface.
- **Android app** — a Kotlin/Compose app (Android 10 / API 29 and newer).
- **`nexus-cli`** — a terminal harness for exercising the protocol.

## Downloads

- **Windows** — `Nexus_0.1.0_x64-setup.exe` (NSIS installer) or
  `Nexus_0.1.0_x64_en-US.msi`.
- **Android** — `app-release.apk`.

## Getting started

1. Install Nexus on both devices.
2. Put both on the same Wi-Fi network.
3. Open Nexus on both.
4. Find the other device under **Nearby devices**.
5. Tap **Pair**, and **Allow a new pairing** on the other device.
6. Confirm the same 6-digit code on both screens.

## Known limitations

- **Android clipboard is foreground-only.** Android has allowed only the focused
  app to read the clipboard since Android 10, and Nexus deliberately does not
  work around this (no accessibility hacks, no root). A copy on the desktop
  reaches the phone immediately; a copy on the phone is picked up while Nexus is
  open and focused.
- **Plain text only** — no images, files or rich text.
- **One active connection at a time** per device.
- **Platform support** — Windows and Linux (X11) are primary; Wayland and macOS
  are best-effort and untested. v0.1 installers are published for Windows.

## Not included

Planned for later releases, and intentionally absent from v0.1:

- **v0.2** — file transfer between paired devices.
- **v0.3** — media control and notifications.

## Security notes

- Devices generate their own certificate and private key locally; private keys
  are never transmitted.
- Connections are only accepted between paired, pinned devices.
- No analytics or telemetry; clipboard contents are never written to logs.

## Notes for maintainers

- The Windows installers and the release APK in this release are **signed with
  a throwaway key** used to verify the release pipeline. Replace it with the
  project's real release keys before publishing artifacts.
